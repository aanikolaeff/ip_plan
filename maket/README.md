# Макет: постоянное меню для IP План

Критика текущей навигации приложения + предложение постоянной шапки-меню,
в существующем дизайн-языке проекта (токены из `static/ip_plan/css/style.css`,
Inter/JetBrains Mono, pill-контролы).

## Файлы

- **Current.dc.html** — разметка/CSS текущего состояния (для сравнения).
- **Main.dc.html** — разметка/CSS предложенной шапки + переключение между
  разделами (клик по «IP План» / «ACL» реально переключает раздел — простое
  состояние на клиенте, без реального роутинга).
- **canvas.json** — раскладка и заметки с критикой (координаты артбордов,
  текст замечаний), для контекста.

Кликабельная онлайн-версия (можно поделиться ссылкой):
https://claude.ai/code/artifact/69278587-b8c2-49ca-ae50-6b5b7b789c42

(Полный самодостаточный HTML-файл этого макета — 2.4 МБ, с упакованным
редактором — не выгружен сюда: удобнее смотреть по ссылке выше или собрать
локально из .dc.html-файлов при необходимости.)

## Что не так сейчас

1. Плашка пользователя (имя + «Выйти») висит сама по себе, вне какой-либо
   навигации.
2. Единственный путь в ACL и ОС-справочник — эмодзи-иконки без подписи
   (🛡, 🖴), в одном ряду с «?» и экспортом — разные по значимости функции
   свалены вместе, смысл иконки понятен только по title-подсказке.
3. Нигде не видно, на какой странице ты находишься — индикации активного
   раздела нет.
4. На странице ACL «← IP план» — кнопка "назад" сделана вручную для каждой
   подстраницы (см. `acl_lookup.html`), паттерн не переиспользуется.

## Предложение

Постоянная шапка сверху (тот же приём, что «control strip» у заголовка
таблицы — `background: var(--bg-page)`, hairline снизу):

- слева — табы реальных страниц (**IP План** / **ACL**) с явным активным
  состоянием;
- справа — вспомогательные справочники (**ОС-справочник**, **Справка** —
  по-прежнему открываются модалкой, как сейчас) и разовое действие
  **Экспорт**, отделены от табов вертикальным разделителем;
- правее всего — пользователь и «Выйти», уже часть шапки, а не отдельная
  плашка над hero.

Hero страниц остаётся только для локального контекста: заголовок, действия
(«+ Добавить IP», «Найти»), статистика — без смешивания с навигацией. На ACL
это же убирает нужду в ручной кнопке «← IP план».

Все цвета/шрифты/радиусы/паддинги в `Main.dc.html` — 1-в-1 значения из
`static/ip_plan/css/style.css` (`--accent`, `--border-soft-strong`,
`.btn-add`, `.btn-help`, `.toolbar-input` и т.д.), можно переносить в
`base.html` + отдельный `nav.css` без подгонки на глаз.
