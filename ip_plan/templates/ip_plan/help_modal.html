Справка
Поиск и фильтры

Поле «Поиск» ищет по всем видимым столбцам сразу (адрес, DNS-имя, описание и т.д.).

Фильтр «Статус» и «Подсеть» сужают список до выбранного значения. Фильтр «Роль» — до роли устройства/ВМ, на которые назначен адрес; пункт «Нет роли» показывает только адреса без такого назначения.

Все фильтры и поиск комбинируются между собой.

Столбцы таблицы

Кнопка «Столбцы» открывает список столбцов с чекбоксами — отмеченные показаны, снятые скрыты. «Сбросить по умолчанию» возвращает исходный набор.

Колонки «Адрес», «Статус», «Принадлежность» и «Роль» закреплены слева и не скроллятся при горизонтальном скролле таблицы.

Редактирование прямо в таблице

Двойной клик (для Статуса и Операционной системы — одинарный) по ячейке открывает редактор; Enter сохраняет, Esc отменяет. Курсор показывает, можно ли редактировать поле: текстовый курсор — да, перечёркнутый круг — нет.

Редактируются: DNS-имя, Статус, Описание*, Операционная система†, Назначение, Комментарии.

Только для чтения: CPE, Open Ports, OS Guess — заполняются автоматически сканированием/импортом; Guest OS — синхронизируется из vCenter (только для адресов, назначенных на ВМ). Тэги, IP-адрес и Интерфейс редактируются только в полной форме (кнопка «Открыть» / клик по адресу).

†«Операционная система» — выпадающий список из справочника; пункт «Другое…» открывает обычное текстовое поле для значения, которого нет в справочнике.

*Описание читается из самого адреса, если он ни к чему не назначен, или из устройства, на которое он назначен. Исключение — назначение на виртуальную машину: там показывается (и только показывается, без права правки) описание самой ВМ, потому что оно обновляется автоматической синхронизацией. При наведении на ячейку «Описание» во всплывающей подсказке всегда видно полное значение и, если есть назначение на устройство, — его собственное описание через «›».

Полная форма адреса

Клик по самому адресу или кнопка «Открыть» открывают модальное окно с полным набором полей, включая тэги и комментарии.

Меню действий (⋯) у каждой строки

Проверить доступность — пинг адреса; если отвечает и статус не «Active» — переключает в «Active».

Сканировать порты — nmap-скан первых 1000 портов, результат полностью перезаписывает Open Ports.

Резолв DNS — обратный (PTR) DNS-запрос; если DNS-имя ещё не задано — сохраняет найденное сразу, если задано другое — спросит подтверждение.

Удалить — удаляет адрес из NetBox без возможности восстановить.

Копирование значений

Значок рядом со значением (адрес, DNS-имя, описание) копирует его в буфер обмена без выделения текста вручную.

Свободные диапазоны

При выборе конкретной подсети в фильтре «Подсеть» под занятыми адресами появляются строки незанятых диапазонов. Кнопка «+» у такой строки открывает форму добавления с уже подставленным первым свободным адресом этого диапазона.

Массовое удаление

Чекбоксы слева от каждой строки выбирают адреса (текущей страницы); чекбокс в заголовке — выбрать все на странице. Появляется кнопка «Удалить (N)» — подтверждает удаление сразу всех выбранных.
